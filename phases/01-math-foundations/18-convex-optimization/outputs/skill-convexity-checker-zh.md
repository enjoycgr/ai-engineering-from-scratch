# 凸性检查器 (Convexity Checker)

如何验证优化问题是否为凸问题，以及得到答案后该怎么做。

## 决策清单

1. 目标函数是否为凸？（检查 Hessian 正半定性或使用复合规则。）
2. 所有不等式约束是否都是 g_i(x) <= 0 的形式，且每个 g_i 都是凸的？
3. 所有等式约束是否都是仿射（线性）的？
4. 如果三个答案都是“是”，则问题是凸的。使用带有收敛保证的凸求解器。
5. 如果有任何一个答案是“否”，则问题是非凸的。使用 SGD/Adam 并接受局部最优。

## 如何检验函数的凸性

| 检验 | 适用对象 | 方法 |
|---|---|---|
| 二阶导数 >= 0 | 标量函数 f(x) | 计算 f''(x)。如果 f''(x) >= 0 对所有 x 成立，则为凸。 |
| Hessian 是 PSD | 多元函数 f(x) | 计算 H(x)。如果所有特征值 >= 0 在所有地方成立，则为凸。 |
| 定义检验 | 任意函数 | 对采样的 x, y, t 检验 f(tx + (1-t)y) <= t*f(x) + (1-t)*f(y)。 |
| 复合规则 | 复合函数 | 见下面的复合表。 |
| 限制到一条线 | 多元 f | f 是凸的当且仅当 g(t) = f(x + tv) 对任意 x, v 在 t 上是凸的。 |

## 保持凸性的复合规则

| 操作 | 结果 |
|---|---|
| f + g（均为凸） | 凸 |
| c * f（c > 0, f 凸） | 凸 |
| max(f, g)（均为凸） | 凸 |
| f(Ax + b) 其中 f 是凸的 | 凸 |
| g(f(x)) 其中 g 是凸且非减，f 是凸的 | 凸 |
| g(f(x)) 其中 g 是凸且非增，f 是凹的 | 凸 |
| 凸函数之和 | 凸 |
| 凸函数的点态上确界 | 凸 |

## 常见机器学习目标：凸还是非凸？

| 目标 | 凸？ | 原因 |
|---|---|---|
| MSE: (1/n) sum(y - Xw)^2 | 是 | 在 w 上是二次的，Hessian = (2/n) X^T X 是 PSD |
| 逻辑损失: sum(log(1 + exp(-y_i * w^T x_i))) | 是 | 凸函数之和（log-sum-exp 族） |
| Hinge loss: sum(max(0, 1 - y_i * w^T x_i)) | 是 | 凸（线性）函数的最大值 |
| L2 正则化: lambda * ||w||^2 | 是 | 二次的，Hessian = 2*lambda*I |
| L1 正则化: lambda * ||w||_1 | 是 | 绝对值之和（凸但不可微） |
| Ridge 回归: MSE + L2 | 是 | 两个凸函数之和 |
| LASSO: MSE + L1 | 是 | 两个凸函数之和 |
| Elastic net: MSE + L1 + L2 | 是 | 凸函数之和 |
| SVM (原始): hinge + L2 | 是 | 凸函数之和 |
| 带 softmax 的交叉熵 | 是（在 logits 上） | log-sum-exp 是凸的 |
| 神经网络（任何损失） | 否 | 非线性激活函数创建非凸复合 |
| k-means 目标 | 否 | 离散分配步骤 |
| 矩阵分解: ||X - UV^T||^2 | 否 | 在 U 和 V 上是双线性的 |
| GAN 损失 | 否 | 极小极大，在生成器上非凸 |
| 对比损失 (InfoNCE) | 否 | 带负样本的指数比值的对数 |

## 基于凸性的求解器选择

| 问题类型 | 求解器 | 收敛保证 |
|---|---|---|
| 凸，光滑，无约束 | 梯度下降 | O(1/k) 到全局最小值 |
| 凸，光滑，无约束 | L-BFGS | 超线性到全局最小值 |
| 凸，光滑，无约束 | Newton 方法 | 在最小值附近二次收敛（如果 Hessian 可处理） |
| 凸，光滑，有约束 | 内点法 | 多项式时间 |
| 凸，非光滑 (L1) | 近端梯度 / ISTA | O(1/k) 到全局最小值 |
| 凸，非光滑 (L1) | ADMM | 灵活，处理约束 |
| 凸，二次 | 共轭梯度 | 在 n 步内精确求解 |
| 非凸，光滑 | SGD / Adam | 收敛到局部最小值 |
| 非凸，光滑 | SGD + 重启 | 平均情况下更好的局部最小值 |
| 非凸，光滑 | 过参数化 + SGD | 平坦最小值，良好泛化 |

## 常见错误

- 因为损失函数是凸的就假设问题是凸的。损失必须在你要优化的参数上是凸的。交叉熵在 logits 上是凸的，但神经网络从输入到 logits 的完整映射是非凸的。
- 在非凸问题上使用 Newton 方法。Hessian 可能有负特征值，导致 Newton 移向鞍点或最大值而不是最小值。
- 忘记 L1 正则化使目标在零点处不可微。标准梯度下降效果不好。使用近端梯度下降或次梯度方法。
- 通过形成 A^T A 使条件数平方。如果你需要求解最小二乘问题且 A 是病态的，使用 QR 或 SVD 而不是正规方程。
- 未检查就声明问题非凸。许多机器学习问题（线性模型、SVM、逻辑回归）是凸的，受益于更强的求解器。

## 快速测试：我的问题是凸的吗？

```
1. 写出目标：最小化 f(w) 满足约束
2. 对于 f(w) 中的每一项：
   - 它是带 PSD 矩阵的二次型吗？ -> 凸
   - 它是一个范数吗？ -> 凸
   - 它是 log-sum-exp 吗？ -> 凸
   - 它涉及 w 的非线性方式（sigmoid(w), w1*w2）？ -> 可能非凸
3. 所有约束是否都是线性或凸不等式？
4. 如果所有项都是凸的且约束是凸/线性的 -> 问题是凸的
5. 如果有任何项是非凸的 -> 问题是非凸的
```
