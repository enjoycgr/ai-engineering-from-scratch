# 模型评估策略

一个正确评估任何机器学习模型的检查清单。按此顺序执行，以避免最常见的评估错误。

## 第一步：正确划分数据

- 在任何预处理（缩放、插补、编码）之前先划分
- 分类任务使用 stratified splits (分层划分)
- 保留一个测试集，只在最后恰好使用一次
- 小数据集使用 5-fold 或 10-fold cross-validation (交叉验证)，而不是单一划分
- 时间序列使用基于时间的划分（绝不打乱顺序）

## 第二步：选择合适的指标

### 分类

| 场景 | 使用此指标 | 原因 |
|-----------|----------------|-----|
| 类别平衡，简单比较 | Accuracy (准确率) | 易于解释，类别相等时有意义 |
| False positives (假正例) 代价高（垃圾邮件过滤器、欺诈警报） | Precision (精确率) | 衡量被标记的项目中有多少确实是正类 |
| False negatives (假反例) 代价高（癌症筛查、安全检测） | Recall (召回率) | 衡量实际正类中有多少被捕捉到 |
| 需要平衡 precision 和 recall | F1 Score (F1分数) | 调和平均数，惩罚极端不平衡 |
| 跨阈值比较模型 | AUC-ROC | 与阈值无关的排名质量 |
| 不平衡数据 | F1、AUC-ROC 或 PR-AUC | 类别不平衡时 accuracy 具有误导性 |

### 回归

| 场景 | 使用此指标 | 原因 |
|-----------|----------------|-----|
| 标准回归，异常值可接受 | RMSE (均方根误差) | 与目标变量单位相同，对大的误差进行惩罚 |
| 对异常值稳健的评估 | MAE (平均绝对误差) | 对所有误差一视同仁，不受异常值主导 |
| 在不同尺度上比较模型 | R-squared (R平方) | 归一化的 0-1 尺度（解释的方差比例） |
| 业务需要金额表示 | MAE 或 RMSE | 可直接解释为误差幅度 |

## 第三步：建立基线

在评估模型之前，先计算基线性能：
- 分类：多数类预测器（始终预测最常见的类别）
- 回归：始终预测训练目标的均值
- 任何无法超越这些基线的模型都没有在学习

## 第四步：交叉验证

- 使用 K-fold (K折交叉验证)（K=5 或 K=10）以获得稳定的估计
- 分类使用 stratified K-fold (分层K折交叉验证)
- 报告各折的均值和标准差
- 均值=0.85 且标准差=0.02 的模型比均值=0.87 且标准差=0.10 的模型更可靠

## 第五步：统计比较模型

- 不要在没有检查显著性的情况下选择平均分数最高的模型
- 使用 cross-validation (交叉验证) 各折上的配对 t 检验
- 如果 |t| < 2.78（K=5，df=4，p<0.05），差异可能是偶然的
- 当性能差异不显著时，考虑更简单的模型

## 第六步：检查常见错误

- Data leakage (数据泄漏)：是否有任何测试数据信息流入训练？（划分前进行缩放、从目标变量派生的特征）
- Class imbalance (类别不平衡)：accuracy 是否在掩盖少数类的差性能？
- Overfitting (过拟合)：训练性能和验证性能之间的差距是否很大？
- 评估次数过多：你是否查看测试集超过一次？

## 第七步：报告最终性能

- 在训练集 + 验证集合并后的数据上训练
- 在保留的测试集上恰好评估一次
- 如果可能，报告所选指标的置信区间
- 说明与基线的比较（比随机/均值好多少）
