# 面向 LLM 的群体优化（PSO、ACO）

> 生物启发式优化正在 LLM 领域强势回归。**LMPSO**（arXiv:2504.09247）将 PSO 应用于提示词优化：每个粒子的速度是一条 prompt，由 LLM 生成下一个候选解；在结构化序列输出（数学表达式、程序）上表现优异。**Model Swarms**（arXiv:2410.11163）将每个 LLM 专家视为模型权重流形上的 PSO 粒子，在仅使用 200 个样本的情况下，在 9 个数据集上相比 12 个基线平均提升 **13.3%**。**SwarmPrompt**（ICAART 2025）混合 PSO + 灰狼算法进行提示词优化。**AMRO-S**（arXiv:2603.12933）是受 ACO 启发的信息素专家系统，用于多智能体 LLM 路由——实现 **4.7 倍加速**、可解释的路由证据，以及质量门控的异步更新，将推理与学习解耦。本课在提示词参数空间上实现 PSO，在智能体路由上实现 ACO，分析这些经典算法为何适合 LLM 时代，以及何时不适合。

**类型：** 学习 + 构建
**语言：** Python（标准库）
**前置要求：** Phase 16 · 09（并行群体网络）、Phase 16 · 14（共识与 BFT）
**时间：** 约 75 分钟

## 问题

你有一个提示词，在任务评估上得分 62%。你想提升它。最朴素的做法是手动无梯度调优，但扩展性很差。强化学习需要奖励信号和足够的 rollout 才能训练。通过提示词做反向传播实际上不可行——提示词是离散字符串，不是可微参数。

经典生物启发式优化——用于连续搜索空间的 PSO（粒子群优化），用于路径选择的 ACO（蚁群优化）——正是为这种场景设计的：无梯度、基于种群、单次评估成本低。将它们与 LLM 配对用于无梯度搜索步骤，你会得到一个 surprisingly practical 的优化器。

同样的模式也适用于多智能体系统中的智能体*路由*。ACO 风格的信息素轨迹记录了哪个智能体在哪种任务类型上表现最好，让路由器利用该轨迹，同时信息素会衰减，以便重新发现路径。

## 概念

### PSO 回顾（Kennedy & Eberhart, 1995）

PSO（粒子群优化）：在连续搜索空间中的一群粒子。每个粒子有位置 `x_i` 和速度 `v_i`。每次迭代：

```
v_i <- w * v_i + c1 * r1 * (p_best_i - x_i) + c2 * r2 * (g_best - x_i)
x_i <- x_i + v_i
evaluate fitness(x_i)
update p_best_i if improved
update g_best if global best
```

其中 `p_best` 是粒子自身最优，`g_best` 是群体最优，`w, c1, c2` 是惯性 + 认知 + 社会权重，`r1, r2` 是随机因子。

### 面向 LLM 输出的 PSO —— LMPSO

arXiv:2504.09247 将 PSO 适配到 LLM 生成的结构化输出（数学表达式、程序）。每个粒子是一个候选输出。速度是一条*提示词*，描述如何将当前输出朝向个人/全局最优修改。LLM 根据速度提示词生成新输出。速度的"惯性"部分是一条类似"只做小的增量修改"的提示词。

这种方式在以下情况表现良好：
- 输出是结构化的（可解析、可评估）。
- 适应度是自动计算的（测试运行、算术求值）。
- 种群规模较小（约 10-30 个粒子），因此总 LLM 调用量可控。

当适应度需要人工评审时效果不佳——每次迭代的成本会变得过高。

### Model Swarms

arXiv:2410.11163 将 PSO 从输出层推进到*模型*层。每个"粒子"是一个专家 LLM（参数）。群体通过无梯度更新将参数向集体最优移动。报告结果：在仅 200 个样本/迭代的情况下，在 9 个数据集上相比 12 个基线平均提升 13.3%。

关键洞察是：LLM 专家模型在共享参数流形（adapter 权重、LoRA delta）中已经彼此接近。在这个低维子空间上做 PSO 既便宜又有效。

### ACO 回顾（Dorigo, 1992）

ACO（蚁群优化）：蚂蚁在图上遍历；每条路径有一条信息素轨迹。蚂蚁移动概率按信息素强度加权。完成任务的蚂蚁按解的质量比例沉积信息素。信息素随时间衰减。

### AMRO-S —— 面向智能体路由的 ACO

arXiv:2603.12933 将 ACO 用于多智能体路由。每种任务类型是一个"目的地"；每个智能体是一条可选路径。信息素在产生好输出的路径上增强。关键贡献：

- **可解释的路由证据。** 信息素强度是人类可读的信号。
- **质量门控异步更新。** 信息素仅在质量检查通过后更新，将推理与学习解耦。
- 在多智能体路由基准上实现 **4.7 倍加速**。

质量门控至关重要：没有它，快但错的智能体会积累信息素，系统将锁定在劣质路径上。

### 何时将 PSO / ACO 用于 LLM

**使用 PSO 的场景：**
- 搜索空间是连续的，或可以映射到连续参数（提示词嵌入、LoRA 权重、数值生成参数）。
- 适应度计算便宜且自动。
- 种群规模可以很小（10-30）。

**使用 ACO 的场景：**
- 你有路由或路径选择问题。
- 决策会随时间强化（相同的任务类型反复出现）。
- 你需要路由决策的可解释证据。

**不要使用两者的场景：**
- 适应度需要人工评审（每次迭代成本过高）。
- 搜索空间是离散的、组合性的，而 PSO 无法覆盖（改用遗传算法）。
- 实时决策有严格延迟要求（PSO/ACO 收敛速度相对单遍启发式较慢）。

### 为什么生物启发式方法仍然胜出

基于梯度的方法需要可微信号。LLM 输出和路由决策并非天然可微。伪梯度方法（强化学习路由器、DPO 风格提示词调优器）有效，但需要昂贵的训练。

PSO 和 ACO 只需要一个*评估器*函数。如果你能对一个候选输出或路由决策打分，你就可以在该空间上优化。这使得适用门槛大大降低。

### 实际限制

- **种群预算。** N 个粒子 × T 次迭代 × 单次评估成本。以 LLM 评估约 $0.02/调用计算，20 个粒子的 PSO 运行 50 次迭代约花费 $20。请相应规划。
- **探索与利用。** 信息素衰减率和 PSO 惯性之间的权衡；衰减过快 → 遗忘解；衰减过慢 → 卡在早期局部最优。
- **灾难性漂移。** 如果适应度景观变化（新数据分布），两种算法都可能先收敛后发散。需监控最优适应度的稳定性。

## 构建

`code/main.py` 实现了：

- `LMPSO` —— 在数值提示词参数（temperature、top_k 权重）上的 PSO。每个粒子的"LLM 生成"被模拟为脚本化适应度函数。运行算法 30 次迭代并展示 g_best 收敛过程。
- `AMRO_S` —— ACO 风格路由。3 个智能体、4 种任务类型、信息素矩阵、100 次路由任务。打印（task_type → agent choices）随时间的分布，以展示轨迹形成。
- 对比：相同样本流上的随机路由 vs ACO 路由。衡量质量和延迟。

运行：

```
python3 code/main.py
```

预期输出：
- LMPSO：g_best 适应度从随机值提升到接近最优，历时 30 次迭代。
- AMRO-S：信息素表按任务类型稳定到正确的智能体；ACO 路由在质量上比随机路由提升约 30-40%，同时减少延迟（更少重试）。

## 应用

`outputs/skill-swarm-optimizer.md` 帮助你在 PSO、ACO、遗传算法和基于梯度的优化器之间为 LLM / 智能体优化问题做出选择。

## 交付

- **从小规模开始。** 10-20 个粒子，20-50 次迭代。仅当收敛曲线显示明显收益时才扩大规模。
- **记录每次迭代的信息素或 g_best。** 没有轨迹的群体优化器调试是痛苦的。
- **质量门控更新。** 尤其针对 ACO 路由：快但错的智能体绝不能积累信息素。
- **分布变化时重置衰减。** 当你的评估分布变化时，陈旧的信息素已经失效；临时重置或加倍衰减率。
- **限制每次迭代成本。** 输出每次迭代的成本指标。每次迭代花费 $500 却只提升 0.5% 的 PSO 是不可交付的。

## 练习

1. 运行 `code/main.py`。观察 LMPSO 收敛。将种群规模分别设为 5、10、20、50。在什么规模下收敛时间达到饱和？
2. 实现一个"灾难性漂移"实验：第 30 次迭代后改变适应度函数。PSO 适应有多快？重置 `p_best` 是否有帮助？
3. 为 AMRO-S 添加质量门控：仅在评估分数 > 0.7 的运行上沉积信息素。这与无门控版本相比如何改变收敛？
4. 阅读 LMPSO（arXiv:2504.09247）。将论文中的"速度作为提示词"映射回你的数值速度。模拟中丢失了什么，保留了什么？
5. 阅读 AMRO-S（arXiv:2603.12933）。实现解耦的"推理快速路径"与异步信息素更新。在持续负载下，这会如何改变系统延迟？

## 关键术语

| 术语 | 人们怎么说 | 实际含义 |
|------|-----------|---------|
| PSO | "Particle Swarm Optimization" | Kennedy-Eberhart 1995。基于种群的无梯度优化器。 |
| ACO | "Ant Colony Optimization" | Dorigo 1992。通过信息素轨迹进行路径/路由优化。 |
| LMPSO | "PSO with LLM generation" | arXiv:2504.09247。速度是一条提示词；LLM 产生候选解。 |
| Model Swarms | "PSO on expert weights" | arXiv:2410.11163。在模型参数子空间上的无梯度更新。 |
| AMRO-S | "ACO for agent routing" | arXiv:2603.12933。任务类型 × 智能体的信息素矩阵。 |
| p_best / g_best | "Personal / global best" | 每个粒子和整个群体目前找到的最优解。 |
| Pheromone | "Routing memory" | 边上的强度；随时间衰减；按质量沉积。 |
| Quality-gated update | "Only learn from good runs" | 信息素沉积以质量检查为条件。 |
| Catastrophic drift | "Distribution shift" | 适应度景观变化；旧的 p_best 和信息素变得过时。 |
