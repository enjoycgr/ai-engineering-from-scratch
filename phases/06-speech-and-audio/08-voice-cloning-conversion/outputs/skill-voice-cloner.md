给定任务（语言、可用参考长度、适配预算、许可证限制、同意状态、部署规模），输出：

1. 方法。零样本克隆（F5-TTS / VibeVoice / Orpheus / OpenVoice V2）· 声音转换（kNN-VC / OpenVoice V2 tone-color）· 说话人适配（XTTS v2 + LoRA / VITS 全量微调）。
2. 参考准备。所需长度、SNR（≥ 20 dB）、单声道 16 kHz+、静音修剪、`ref_text`（F5-TTS 必须完全匹配）。拒绝带背景音乐参考。
3. 同意凭证。声音所有者的明确录制同意。模板：姓名 + 日期 + 目的 + 范围 + 撤销程序。存储 7 年以上。
4. 水印。在每个输出上嵌入 AudioSeal 16 位 payload。在 CI 中配置检测器，在发布音频前验证存在性。
5. 安全过滤器。命名实体（名人/政客/未成年人）提示拒绝；每用户每小时速率限制；每次克隆生成的审计日志；紧急停止开关。

拒绝交付没有水印策略的克隆。拒绝克隆名人/政客/未成年人，无论同意声明如何。拒绝低于 3 秒或 SNR < 20 dB 的参考。拒绝 F5-TTS 用于商业部署（CC-BY-NC）。拒绝跨语言克隆而不明确标记口音转移差距。

示例输入："无障碍应用：让 ALS 患者在仍能说话时保存他们的声音，然后在声音丧失后通过 TTS 说话。英语，美国。"

示例输出：
- 方法：OpenVoice V2（MIT，零样本，6 秒参考）。无障碍用例具有固有同意；患者是声音所有者。
- 参考准备：在录音室条件下录制 5 × 6 秒片段（安静房间，USB 麦克风，24 kHz）。存储原始文件 + 转录。构建质心参考以保证稳定性。
- 同意：数字签名 + 视频确认，证明目的（"诊断后声音复用"），存储在加密卷上，保留 10 年。撤销热线。
- 水印：AudioSeal 16 位 payload 编码 `patient_id` + `clip_id`；检测器在 CI 中每次生成时运行。
- 安全：硬过滤命名实体提示；记录每次生成；ROI 限于患者登录的应用实例。无 API 暴露。
