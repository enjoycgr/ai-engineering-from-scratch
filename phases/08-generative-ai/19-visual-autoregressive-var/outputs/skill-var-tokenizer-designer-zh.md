给定图像目标（分辨率、通道、彩色 vs 灰度、数据集大小、下游 LM 计算预算、目标 FID），输出：

1. 尺度计划。从 1×1 到 (H/p) × (W/p) 的 K 个分辨率级别列表。256×256 默认 10 个尺度，512×512 默认 14 个。用 LM 的有效序列长度（尺度面积之和）和每轮传播尺度内并行预算来论证 K。
2. 码本。所有尺度共享单一码本大小 V（典型 4096 / 8192 / 16384）。根据数据集大小和解码器容量选择 V。在校准 batch 上确认码本使用率保持在 50% 以上，否则缩小 V。
3. 残差共享。确认尺度 1..K 通过累加上采样 embedding 一起重构隐变量（残差 VQ）。声明 patch size p 和 VAE 主干（VQGAN 风格判别器开/关、感知损失权重）。
4. 解码器。将累加隐变量映射回像素的 VAE 解码器。从 VQGAN 解码器、VAR 论文解码器或更轻量的 MAGVIT 风格解码器中选择。根据 FID 目标和解码器 VRAM 论证。
5. 位置嵌入。确认 (scale_index, row, col) 三元组，每个尺度一个 learned embedding (学习嵌入) 和尺度内的 2D sin-cos。拒绝扁平 1D 位置；LM 需要尺度标签来应用正确的条件。

拒绝为 VAR 提供非残差多尺度分词器。没有累加残差的话，下一尺度条件变得定义不清，LM 优化的目标与论文证明的不同。拒绝单独的每尺度码本，除非 V 根据较小尺度的像素数校准且码本坍塌得到缓解。当 K × 平均尺度面积超过 LM 最大序列长度减去文本条件余量时，拒绝下一尺度预测。

示例输入："ImageNet 类别条件 256×256，数据集 1.2M，LM 预算 1.5B 参数，目标 FID 低于 5.0。"

示例输出：
- 尺度计划：K=10，尺寸 1, 2, 3, 4, 5, 6, 8, 10, 13, 16。总 token 671。
- 码本：共享，V=4096。在 ImageNet 256 上期望 70-80% 使用率。
- 残差共享：已确认；p=16，VQGAN 主干带感知 + 对抗损失，残差和重构 f。
- 解码器：VQGAN 解码器，4 个上采样块，无额外精炼器。
- 位置嵌入：(scale, row, col) 三元组，学习尺度 token + 尺度内 2D sin-cos。
