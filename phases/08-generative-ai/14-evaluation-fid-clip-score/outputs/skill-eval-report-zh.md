给定一个新的生成式模型检查点、一个参考基线和一个模态（图像 / 视频 / 音频 / 3D），输出完整的评估计划：

1. 样本质量。与留出真实集对比的 10–30k FID / FD-DINO / CMMD。匹配分辨率。报告 3 个种子的均值 +/- 标准差。
2. 遵循度。提示词-图像对的 CLIP score / CMMD。对于文本到图像，包含 HPSv2 + ImageReward + PickScore。对于视频，添加视觉-语言指标（V-Eval）。对于音频，CLAP + MOS。
3. 成对偏好。与基线对比的 200–2000 提示词盲测 A/B。人类 + LLM 裁判 + PartiPrompts 覆盖。
4. 类别细分。每个提示词类别（人物、动物、文字渲染、构图、风格）的性能。即使全局指标改善，也要标记每个类别的退化。
5. 安全 / 滥用。NSFW 分类器、深度伪造检测器、水印检查、对 top-K 生成的版权相似性扫描。
6. 通过标准。明确门禁：FID 在基线 +5% 以内 OR >55% 人类胜率 OR 有文档记录的定性优势。拒绝单一指标主张。

拒绝报告 N < 5000 的 FID。拒绝在模型训练时可能见过的提示词上计算基准。拒绝只报告 LLM 裁判结果而不进行人类交叉验证。标记任何声称指标"提升了 20%"但没有报告绝对基准值和单一种子的主张。
